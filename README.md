# FIAP PÓS-TECH — IA para Devs

Repositório de projetos e materiais da pós-graduação **IA para Devs** da FIAP POSTECH. As três primeiras fases dos Tech Challenges exploram um contexto acadêmico de apoio à saúde e síndrome dos ovários policísticos (SOP/PCOS); a quarta propõe monitoramento multimodal hospitalar.

O [índice do projeto da Fase 4](Materiais/Fase%204%20-%20AI%20Text%20%26%20Media/Projeto%20de%20monitoramento%20multimodal/README.md) reúne contexto, relatório, apresentação e guias de estudo e reprodução. Os projetos relacionados a saúde são acadêmicos e não foram validados para uso clínico. Resultados e limitações específicos estão nos relatórios de cada fase.
